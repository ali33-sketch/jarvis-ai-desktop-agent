# Roadmap

## Phase 0 — Planning and Documentation

Goal: define the product, architecture, requirements, and rollout plan.

Completed:

- project purpose defined
- architecture overview created
- product spec drafted
- roadmap initialized

## Phase 1 — Foundation

Goal: build the desktop app shell and basic orchestration.

Planned work:

- create Tauri app structure
- create React app shell
- define backend service boundaries
- implement LLM adapter and model configuration
- add structured tool definitions
- create event bus / status updates

## Phase 2 — Local Tools

Goal: enable safe local automation.

Planned work:

- PowerShell integration
- app launch commands
- file and folder operations
- process introspection
- simple system info queries
- permission safety gates

## Phase 3 — Browser and Web Tools

Goal: add web-driven workflows.

Planned work:

- Playwright integration
- browser open / navigate / click / type tools
- page reading and result parsing
- search workflows
- content extraction for summarization

## Phase 4 — Memory and Personalization

Goal: make the assistant user-specific.

Planned work:

- persistent user profile
- memory database
- preference handling
- project directory tracking
- long-term facts storage

## Phase 5 — Voice Experience

Goal: add natural conversational interaction.

Planned work:

- STT via Whisper or equivalent
- wake-word detection
- TTS responses
- voice-driven actions
- voice status overlays

## Phase 6 — Multi-Agent System

Goal: route requests to specialized agents.

Planned work:

- orchestrator agent
- researcher agent
- coding agent
- file agent
- system agent
- shared memory and context layer

## Phase 7 — Verification and Safety Hardening

Goal: make the system reliable and safer.

Planned work:

- tool approval workflow
- result verification loops
- retry logic
- user intervention gates
- logging and audit trail

## Phase 8 — Visual Command Center

Goal: make the product feel like a polished futuristic assistant.

Planned work:

- world monitor dashboard
- activity cards and agent statuses
- visual command center
- animated AI status indicators
- custom themes

## Phase 9 — Product Maturity

Goal: ship a usable, stable assistant.

Planned work:

- UX polish
- onboarding flow
- configuration and settings
- error reporting
- release packaging
